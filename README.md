# Cactus Directory Module

Map-based listings for Cactus. Categorise entries, pin a few as featured, drop a pin with free geocoding from OpenStreetMap, and let visitors browse a public directory with maps, filters and search.

See the [wiki](https://github.com/usersaynoso/cactus-foundation/wiki/Directory) for full documentation.
